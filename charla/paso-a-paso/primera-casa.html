EL MACHETE · LA CASA JURÍDICA

Tu primera casa jurídica

El paso a paso de la charla para pasar de prompts sueltos a una casa con habitaciones, reglas y llaves que tu equipo pueda copiar. No vas a programar ni una línea.

Los prompts se olvidan. Las casas se heredan.

El plano en una mirada

Plugin = la casaEl paquete con todo lo que tu despacho sabe hacer en un tema.
Skills = habitacionesCada una hace una sola tarea, siempre igual. La cocina no es para dormir.
Playbook = manual de convivenciaTus reglas: cómo se hace, qué se verifica y qué nunca se hace.
Agentes y scripts = la obraLos que hacen el trabajo pesado dentro de la casa.
GitHub = el gato con superpoderesDonde guardas la casa. Registra cada cambio, quién y cuándo.
Marketplace = el condominioVarias casas, las mismas reglas y una sola portería para tu equipo.

Los 7 pasos

0 de 7 listos
  1. 1

    Ordene la casa antes de invitar

    Elige un proceso que repitas cada semana y arma una carpeta clara. Si la carpeta se llama "Cosas", Claude te devuelve cosas.

    Contratos_PI/ ├── 01_Solicitudes/ correos y solicitudes que llegan ├── 02_Contratos_marco_y_otrosies/ lo firmado que hay que respetar ├── 03_Contratos_modelo/ los que ya te quedaron bien └── 04_Entregables/ vacía: aquí trabaja Claude
  2. 2

    Abra Claude Code en esa carpeta

    Claude Code es Claude trabajando dentro de tus carpetas: las lee, las ordena y crea archivos. Ábrelo desde la app de escritorio de Claude o desde la terminal, y escoge la carpeta del paso 1 como carpeta de trabajo.

    Dice "code", pero no vas a programar.

  3. 3

    Cuéntele su proceso

    Un solo mensaje describe lo que haces y pide la casa. Cambia lo que está en amarillo por tu caso.

    PROMPT PARA COPIAR
    Cada semana recibo por correo [una solicitud de contrato de propiedad intelectual]. Estudia mis carpetas y créame un plugin llamado [casa-propiedad-intelectual], con un playbook con mis reglas (cómo redacto, qué verifico y qué nunca hago) y una skill por cada paso: [leer la solicitud, analizar el contrato marco y los otrosíes, proyectar el contrato con mi formato y armar un informe para mi revisión]. Muéstrame el plano antes de construir.
  4. 4

    Apruebe el plano

    Claude te pregunta lo que necesita y te muestra el plano: el techo (plugin), las habitaciones (skills) y el manual (playbook). Revísalo como revisarías una minuta. Cuando te convenza, dile:

    Aprobado. Constrúyela.

    Ningún maestro de obra serio pega un ladrillo sin que firmes el plano. Si algo no te gusta, pídele el cambio antes de aprobar.

  5. 5

    Súbala al gato con superpoderes

    Guarda la casa en un repositorio privado de GitHub. Ahí no van expedientes: van tus reglas y tus habitaciones, que son archivos livianos de texto.

    PROMPT PARA COPIAR
    Crea un repositorio privado en GitHub llamado [casa-propiedad-intelectual], sube la casa y escribe un README que le explique a mi equipo, en español sencillo, para qué sirve cada habitación.

    Necesitas una cuenta de GitHub conectada en ese computador. Conéctala antes de este paso.

  6. 6

    Arme su condominio e instale

    Instala la casa como marketplace para que tú y tu equipo la tengan en Claude con las mismas reglas. En Claude Code se hace con dos comandos:

    claude plugin marketplace add [tu-usuario]/[casa-propiedad-intelectual] claude plugin install [casa-propiedad-intelectual]@[nombre-del-marketplace]

    El nombre del marketplace es el que quedó en el archivo .claude-plugin/marketplace.json de tu casa. Si no lo sabes, pregúntaselo a Claude. Para usarla también en Claude Cowork, agrega el mismo repositorio desde la sección de plugins de la app.

    Tu compañero solo necesita estos dos comandos para tener la misma casa.

  7. 7

    Úsela y revise con lupa

    Abre un chat nuevo en tu carpeta y dale la orden del día. La casa sigue sus pasos y te entrega el documento con su auditoría para que tú lo revises.

    Me llegó un nuevo contrato.

Las 3 reglas de la casa

  1. La IA no firma. Tú firmas. La responsabilidad profesional no se delega.
  2. Sin fuente, no existe. Toda norma, hecho o cifra apunta a un documento verificable.
  3. El método es tuyo. Claude ejecuta tu playbook. Si el método es malo, la IA lo hace mal más rápido.
Arranca mañana.

Tu primera casa, así sea con una sola habitación.
